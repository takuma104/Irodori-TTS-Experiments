# 読み改善: 製品用モデル（JKYB を使わないデータと評価）

- 開始日: 2026-09-30
- 前段: [yomi_m3.md](yomi_m3.md)（評価用モデル S8: JKYB 94.88%）

## 方針

評価用モデル（S1〜S8）は JKYB の文を学習に使っていないが、次の点で JKYB に依存していた。

- 常用漢字の音訓の表を JKYB のキーから作っていた。
- JKYB の対象語の半分（B 群）を学習から除外していた。
- 設定の選択を JKYB 全体の結果で行っていた。

製品用モデルでは、この3つをすべて外す。

- 読みの表は KANJIDIC2（常用漢字 = 学年 8 以下）から作る（`build_yomi_lexicon.py --reading-table kanjidic2`、
  `data/yomi_prod/`）。B 群の除外はない。
- 学習データは実コーパスの文を使う（Wikipedia、青空文庫の学習用の作品）。
- 開発中の評価と設定の選択は、JKYB 以外の評価セットで行う。JKYB は最後に外部の指標として1回測るだけにする。

## 1. 形態素解析器の読みの一致率

Wikipedia 日本語版の 5 万文（シャード 1）で、MeCab + UniDic 3.1.0 と SudachiPy（mode C）の読みを比べた
（`scripts/analyze_reading_agreement.py`、詳細は `outputs/production/reading_agreement.md`）。
両方の区切りが一致する位置で文を切り、漢字を含む区間ごとに比べた。

| JMdict での扱い | 区間 | UniDic と Sudachi が一致 | 3つとも一致 |
|---|---:|---:|---:|
| 読みが1つの語 | 244,137 | 99.0% | 98.1% |
| 同形異音語 | 80,974 | 94.0% | 92.5% |
| JMdict にない語 | 51,017 | 93.1% | – |
| 全体 | 376,128 | 97.1% | – |

- 食い違いの多くは、1文字の区間の文脈による読み分け（月 ツキ/ガツ、他 ホカ/タ）、固有名詞、数字だった。
- 同形異音語は、2つの解析器が同じ誤りをすることがある（大神→ダイジン、数多→スウタ）。一致していても
  正しいとは限らないので、LLM で読みを検証する。
- 自然な文章に出てくる語の大半は、今のモデルでも読める常用語だった。コーパスを頭から処理するより、
  辞書の難しい語を起点にコーパスから文を探すほうが効率がよい。

## 2. JKYB を使わない評価セット

| 評価セット | 内容 | 件数 | ベース | S8 |
|---|---|---:|---:|---:|
| JSUT basic5000（人手の読み） | 学習の一般文に使っていない文の、文全体の読みの誤り率（kana-whisper） | 2,236 文 | CER 1.881% | 1.834%（改善 135・悪化 117） |
| 青空文庫ルビ（評価用の作品） | ルビの付いた難読語の読み（JKYB 形式、1文1項目） | 3,000 項目 | 62.50% | 62.73%（直った 51・壊れた 44） |

- JSUT: `sarulab-speech/jsut-label` の `kana_level0`（CC-BY-SA 4.0）。一般的な文の読みの退行チェックに使う。
- 青空文庫: 新字新仮名で著作権の切れた作品を、作品 ID のハッシュで評価用（約 1 割）と学習用に分けた。
  ルビが辞書（JMdict）か解析器の読みのどれかと一致するものだけを残した（作家独自の当て字を除く）。
  385 作品、3,000 項目（`scripts/make_aozora_ruby_eval.py`、`outputs/yomi_eval/aozora_rows.jsonl`）。
- 青空文庫の誤りは、ほとんどが本当の読み誤りだった（墻 カキ→エク、彼処 アスコ→カレトコ、葛籠 ツズラ→ツズカゴ、
  金盥 カナダライ→キンザイ）。文学作品の語彙（古い語、常用外の漢字）は S8 の学習データの範囲外で、
  学習した語の項目（748）でも 65.0% → 66.2% にとどまった。

## 3. 製品用の学習データ

- **Wikipedia**: 語彙表（KANJIDIC2 版）のバケット A〜F の語のうち、語幹が2文字以上のもの（5.5 万語幹）を、
  Wikipedia の 304 万文（シャード 2〜5）から Aho-Corasick で探した（`scripts/retrieve_corpus_sentences.py`）。
  次の条件をすべて満たす文だけを残した。
  - 語幹の前後に漢字が続かない。
  - 語幹が文中にちょうど1回だけ出る。
  - UniDic と Sudachi の両方が語幹を1つの区間として区切り、辞書と同じ読みをする。

  23,097 語に文が見つかった。そのうち、これまでの学習データにない 12,060 語・44,379 文を採った
  （`scripts/select_corpus_targets.py`）。同形異音語の文（10,528 文）は LLM で読みを選択式で検証する
  （`scripts/verify_homograph_sentences.py`）。
- **青空文庫の学習用の作品**: 評価用とは別の作品から、ルビの付いた語をそのまま対象語にする
  （`scripts/make_aozora_ruby_train.py`、バケット R）。読みは人が付けたものなので LLM の検証は要らない。
  辞書か解析器と一致するルビだけを使う。
- どちらも、これまでと同じくベースが漢字のまま読み誤る行だけにかなの教師を使う（`scripts/run_yomi_data.sh`）。

S8 から、これまでのデータと合わせて 15,000 ステップ学習する（S9、`scripts/run_prod.sh`、実行中）。
