# 読み改善 M3: 語彙を約 10 倍にした学習

- 実施日: 2026-09-29
- 前段: [yomi_m1_m2_pilot.md](yomi_m1_m2_pilot.md)（学習の設定はパイロットの S4）
- 出力: [outputs/yomi_m3/](../../outputs/yomi_m3/)、[outputs/yomi_eval/s5_top4_ctx/](../../outputs/yomi_eval/s5_top4_ctx/)
- 実行: `scripts/run_m3_data.sh`、`scripts/run_m3_train.sh`

## 結論（途中経過）

**S7 まで（2026-09-30）**: さらに 12,000 ステップ続けた S7（合計 33,000 ステップ）で、JKYB 全体は
**94.04% → 94.64%（+0.61pt、173 / 91、p=5e-7）**。分割される熟語は 86.46% → **88.53%**（+2.07pt、113 / 38、
p=8e-10）、音訓の取り違えは 232 件中 52 件が直った（音→訓 28 / 92）。学習語彙から対象語を除いた B 群でも
+0.54pt（p=6e-4）と有意に改善した。一般文の Whisper CER に退行はない（5.625% → 5.667%、改善 12・悪化 16）。
学習を増やすごとの伸びは小さくなってきている（S5 +0.26、S6 +0.52、S7 +0.61pt）。

**S6 まで（2026-09-29 23:30）**: S5 の学生から 12,000 ステップ続けた S6 で、JKYB 全体は
**94.04% → 94.56%（+0.52pt、159 / 89、p=1e-5）**。A 群 +0.79pt（p=8e-6）、分割される熟語 +1.38pt（p=5e-5）、
音訓の取り違え 232 件中 38 件が直った。学習していない語（dev）も +2.1pt（p=0.001）と、未知の語にも
効き始めた。一般文の Whisper CER（5.625% → 5.633%）と JKYB の Text CER（3.930% → 3.954%）に退行はない。
学習を増やすほど改善が続いているので、さらに 12,000 ステップ続けている（S7）。

以下は S5 時点の結論。

1. JKYB 全体は **94.04% → 94.30%（+0.26pt、直った 103 / 壊れた 68、p=0.009）** と、初めて有意に改善した。
   付表の語は 83.9% → 88.4%（17 / 0）。学習語彙から対象語を除いた B 群でも悪化はなく、+0.31pt だった。
2. ただし、学習した語を使う JKYB の文（864 文）での改善は +1.4pt にとどまり、パイロットの S4
   （316 文で +4.8pt）より小さい。語が約 8 倍に増えたのに学習ステップは約 2 倍で、1 語あたりの学習量が
   足りていない。学習語の対象行の速度差は約 3 割しか縮まなかった（S4 は約 45%、ずれ抑制なしの S3 は 7〜8 割）。
3. 学習を続けて（S6、12,000 ステップ追加）、既知の語がさらに直るかを確かめている。

## 学習（S5）

パイロットの S4 と同じ設定で、パイロットと M3 のデータを合わせて学習した。

- 学習範囲は BERT 上位 4 層。学習率は projector 3e-4、BERT 1e-4。
- 読み誤る行だけにかなの教師を使い、それらの行は 3 倍にした。表現保存の重みは ctx 1・repr 1。
- 9,000 ステップ（学習サンプル 125,330、約 2.3 エポック）で、約 3 時間。

## 学習の継続（S6）

S5 の学生から、同じ設定で 12,000 ステップ続けた（学習率は 200 ステップのウォームアップで元の値に戻し、
コサインで下げる）。合計 21,000 ステップ。学習語の対象行の速度差は、S5 の終わりの約 0.0065 から約 0.0052 に下がった。

| 評価 | ベース | S5 | S6 | S6 の直った / 壊れた | S6 の p |
|---|---:|---:|---:|---:|---:|
| JKYB 全体 | 94.04% | 94.30% | **94.56%** | 159 / 89 | 1e-5 |
| 　音読み | 92.98% | 93.34% | 93.71% | 104 / 53 | 6e-5 |
| 　訓読み | 95.87% | 95.76% | 95.99% | 41 / 34 | 0.49 |
| 　付表の語 | 83.87% | 88.44% | 87.10% | 14 / 2 | 0.004 |
| 　分割される熟語 | 86.46% | 87.01% | **87.84%** | 100 / 50 | 5e-5 |
| 　A 群 | 93.82% | 94.03% | **94.61%** | 96 / 43 | 8e-6 |
| 　B 群 | 94.25% | 94.56% | 94.50% | 63 / 46 | 0.13 |
| JKYB で学習した語を使う文（864 文） | 86.57% | 87.96% | 89.81% | 35 / 7 | 2e-5 |

- 音訓の取り違え（ベースで 232 件）のうち 38 件が直った。向き別では、音→訓 19 / 92、音→別の音 14 / 61、
  訓→音 2 / 53、訓→別の訓 3 / 25。訓→音はほとんど直っていない。
- dev ではバケット A（分割される熟語の音読み）が 80.0% → 85.9%（11 / 1、p=0.006）。学習していない熟語でも、
  音で読む方向に汎化し始めている。
- 退行チェック: 学習にも評価にも使っていない JVS の一般文 500 文で、Whisper の CER はベース 5.625%、
  S6 5.633%（文ごとに改善 13・悪化 20・同じ 467）。JKYB の Text CER も 3.930% → 3.954% で、
  Sentence Kana-CER は 0.900% → 0.839% と改善した。
- 試聴用のセット: `outputs/yomi_eval/s6_cont/listen/`（直った JKYB の文 20 文と一般文 10 文の、
  ベースと S6 の音声。一覧は `index.md`）。

### 試聴の結果（2026-09-30、ユーザー）

- 読みが直った文はおおむね良好。対象外の箇所で違和感があるものも一部あった。
- 対象の漢字だけでなく、同じ語の他の部分まで正しくなる例があった。<暮>春は、ベースの「くれはん」が
  S6 では「ぼしゅん」になり、「春」の読みも直った。学生は語単位で読みを直しており、かな置換の教師
  （語全体をかなにする）の効果と考えられる。
- イントネーションは、<緑>青（ロクショウ）に少し違和感がある程度で、ほかは問題なかった。
  元のチェックポイントが、読みを誤っていても語のイントネーションはある程度学習していた可能性がある。
  プランで懸念していた「かな置換によるアクセントの崩れ」は、試聴した範囲では目立たない。
- 一般文 10 文は、ベースと S6 の違いに気づかず、どちらも問題なかった。
