# 読み改善 M3: 語彙を約 10 倍にした学習

- 実施日: 2026-09-29
- 前段: [yomi_m1_m2_pilot.md](yomi_m1_m2_pilot.md)（学習の設定はパイロットの S4）
- 出力: [outputs/yomi_m3/](../../outputs/yomi_m3/)、[outputs/yomi_eval/s5_top4_ctx/](../../outputs/yomi_eval/s5_top4_ctx/)
- 実行: `scripts/run_m3_data.sh`、`scripts/run_m3_train.sh`

## 結論（途中経過）

1. JKYB 全体は **94.04% → 94.30%（+0.26pt、直った 103 / 壊れた 68、p=0.009）** と、初めて有意に改善した。
   付表の語は 83.9% → 88.4%（17 / 0）。学習語彙から対象語を除いた B 群でも悪化はなく、+0.31pt だった。
2. ただし、学習した語を使う JKYB の文（864 文）での改善は +1.4pt にとどまり、パイロットの S4
   （316 文で +4.8pt）より小さい。語が約 8 倍に増えたのに学習ステップは約 2 倍で、1 語あたりの学習量が
   足りていない。学習語の対象行の速度差は約 3 割しか縮まなかった（S4 は約 45%、ずれ抑制なしの S3 は 7〜8 割）。
3. 学習を続けて（S6、12,000 ステップ追加）、既知の語がさらに直るかを確かめている。

## データ

| 段階 | 件数 |
|---|---:|
| 対象語（パイロットの語を除く）＋対照語 | 22,547 ＋ 1,410 |
| LLM の例文 | 78,677 文（21,434 語、89%） |
| JKYB 形式に変換できた行 | 78,595 |
| ベースが漢字の文で読み誤った対象行 | 24,219（約 33%） |
| そのうち、かな（カタカナ）の教師が正しく読んだ行 | 22,515（93.0%） |
| 易しい行（漢字の文のまま保つ） | 49,775 |
| 対照語の行（ベースが正しく読んだもの） | 4,393 |

パイロットからの変更点として、先に全行を漢字の文でベースに生成させ、ハードマイニングと、易しい行・対照語の
教師データを兼ねた。かなの教師を生成するのは、ベースが読み誤った行だけにした。

ベースが漢字の文で読んだときの正解率（バケット別）: A 67.2%、B 67.9%、C 81.5%、D 74.5%、E 44.7%、
F 64.0%、G（対照） 95.5%。

## 学習（S5）

パイロットの S4 と同じ設定で、パイロットと M3 のデータを合わせて学習した。

- 学習範囲は BERT 上位 4 層。学習率は projector 3e-4、BERT 1e-4。
- 読み誤る行だけにかなの教師を使い、それらの行は 3 倍にした。表現保存の重みは ctx 1・repr 1。
- 9,000 ステップ（学習サンプル 125,330、約 2.3 エポック）で、約 3 時間。
